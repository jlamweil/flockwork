The swarm lane is this repo's own coordination substrate: workers claim tasks and record outcomes through refs under `refs/swarm/` on the project's own origin — `refs/swarm/specs` declares task specs, `refs/swarm/claims` holds leases acquired via create-once CAS pushes (exactly-once: any duplicate claim is rejected by git's ref-CAS), `refs/swarm/tasks` tracks live task state, and `refs/swarm/verdicts` carries one final verdict per task, written only from independent host-side test runs. Claim and verdict commits are ROOT commits so their objects never leak into consumer clones or fetches, and the whole lane can be evicted with a one-transaction namespace delete.
